# Product language and presentation

The product name is Wasit. UI, errors, agent messages, summaries and code comments use English.
Team planning prose may use Indonesian. Raw customer/provider messages and Indonesian place/business names are preserved.

Default theme is Light. Dark and System are explicit choices; a first visit does not automatically choose Dark.
Preserve Wasit typography, spacing, component shapes, colors and motion.

Rupiah: Rp110.000; compact Rp110k / Rp1.5m. Time labels use English day names and WIB.
English clarification choices map to canonical values before parsing.
Machine IDs are stable within the 4.1 contract and are never translated by the UI.
Do not expose internal data/debugging details in normal product flows.
